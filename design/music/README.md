# Licensed recordings (currently none)

Put licensed or commissioned recordings here, unchanged, and describe each one in `sources.json`
(id, title, artist, licence, licenceUrl, page, file, role "gig" or "menu", bpm, style, start/end, changes).
`python3 tools/prepare_music.py` then makes the game MP3s and auto-charts in `game/assets/music/`.

The first set of CC0/CC-BY OpenGameArt tracks was removed: wrong style for AMPED.
Songs and the menu theme are currently generated by the game and played on sampled instruments
(`design/instruments/`, rendered by `tools/render_instruments.py`).
