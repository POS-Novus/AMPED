# Design kit (originals)

Unzip `AMPED_Design_Kit_v1.zip` here and keep its folder structure:

```
design/kit/
  AMPED_Claude_Handoff.md

  docs/
  design/        asset-manifest.json, tokens.json, tokens.css, catalogs
  assets/        brand, characters, world, icons, gear, rhythm, posters, fonts

```
