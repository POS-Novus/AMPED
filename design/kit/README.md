# AMPED design kit v1

Start with **AMPED_Claude_Handoff.md**. Give Claude that file together with this complete folder.

Open **preview/AMPED_Visual_Guide.html** to see the artwork, colour system, seven interface compositions and vector icons. The guide is a static design reference, not the game.

Included: 21 original PNG masters, 101 editable SVG graphics, two font files and licence, design tokens, gear catalog, verified asset manifest, image prompts and the source game brief.

Use standalone images for the initial gameplay slice. Multi-panel concept sheets require preparation; they are not validated animation or sprite atlases. Characters are static cutouts. Audio, animation rigs, complete costume permutations and later standalone environment art remain production tasks.

Keep originals unchanged and create runtime derivatives separately. See the handoff for exact paths, limitations and implementation order.

The tribe expansion adds Headbangers, Punks, Hippies, K-pop and Trappers: 15 character identities with 30 outfit looks. See docs/TRIBES_AND_SKINS.md.
